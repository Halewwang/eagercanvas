# 后台与工作空间 UI 一致性验收

本轮承接[工作空间反馈修复](workspace-feedback-2026-10-19.md)，将新增界面的可见原生下拉框和复选框统一为项目组件，沿用现有黑灰白主题、圆角、字号和焦点样式。未调整后台权限、账户生命周期、项目删除规则或模型配置。

## 调整范围

- 基于已安装的 Naive UI 增加 BaseSelect、BaseCheckbox，并从现有 UI 入口导出。浮层使用项目颜色变量，挂载到 body，避免父容器裁切；不引入新依赖或修改全局主题。
- 后台服务、角色、账户状态筛选使用 BaseSelect；角色设置使用 BaseCheckbox，保留最后角色、超级管理员、自改及禁用保护。移除 AdminControlField 无调用的原生 select 分支。
- 工作空间项目多选使用 BaseCheckbox；复制到团队、转移项目、成员权限使用 BaseSelect；设置字段及保存按钮复用 BaseInput、BaseButton。项目菜单统一为深色，保留现有操作和危险操作颜色。
- 项目选择与批量操作按钮复用 WorkspaceActionPill，补齐禁用和键盘焦点样式。窄屏栅格允许列和内容收缩，避免 320px 下卡片和操作栏被裁切。
- 下拉触发器提供名称、展开与禁用状态；选项提供选中状态。菜单打开时 Escape 先关闭菜单并回焦；再次 Escape 交给外层弹窗关闭。

## 验证

- `npm run check`：1017/1017，通过前端 731、后端 268、脚本 18 项；无失败或跳过，lint 与维护检查通过。
- `npm run build`：通过。测试与构建发生于最终源码，后续仅新增验收文档。
- 真实 Chromium 本地预览：后台三项筛选没有可见原生 select；菜单深色，Enter 打开、方向键选择并正确筛选。五个角色没有原生 checkbox，Space 可切换，禁用状态生效。
- 工作空间三个合成项目覆盖两个所有者和一个只读项目：自定义多选支持鼠标与 Space，只读项禁用；全选、取消及批量按钮外观一致。菜单位于卡片外层，所有者操作完整显示。
- 复制到团队弹窗验证首次 Escape 仅关闭下拉并回焦，第二次关闭弹窗。
- 1440px 桌面、390px 只读角色和 320px 筛选/项目选择布局通过。320px 工作空间主区宽 320px，卡片及操作栏为 x=28、宽 264px，右边界 292px，无横向裁切。
- 最终只读代码复核未发现阻断问题。

浏览器仅连接本地预览，API 指向不可用的本地端口；未修改线上账户或项目，未发起模型请求。本轮三个本地合成项目和合成团队已清理。隐藏文件上传 input、项目已有样式的文本输入继续保留。未做完整读屏器验收。
