# 工作空间与后台反馈修复 · 2026-10-19

延续 [上一轮浏览器反馈修复](browser-feedback-2026-10-19.md)，处理项目菜单、多选删除、加载速度和后台样式五项反馈。

- 项目卡片菜单改用已安装的 Naive UI Dropdown，在卡片层级外显示并自动适应可用空间，保留全部项目操作和危险操作提示。
- 项目页提供 `Select projects`、全选当前列表、清空和删除所选。仅当前可见且明确具有 owner/editor 权限的项目可选；模板、只读分享项目不进入全选。提交前展示数量、永久删除及团队共享影响说明。
- 批量删除复用已有逐项删除接口，最多 3 并发；防止重复提交，部分失败保留仍可操作的失败项供重试。切换用户后停止未发送请求，已发送请求的本地清理限定原用户。切换工作空间或分区会清空选择。
- 项目列表不再等待全部 IndexedDB 画布草稿读取；同用户、同显式工作空间的在途列表请求复用，后续刷新仍请求云端。由服务端决定当前工作空间的默认刷新始终独立请求，防止切换后复用旧空间结果。初载画布预载不再等待模板及收件箱完成，卡片图片延迟解码/加载。云端权限仍是列表依据，不将旧缓存权限直接展示为有效权限。
- 删除标记按用户保留，旧列表响应及离线同步不能恢复已删卡片或草稿；旧用户、旧工作空间响应不能覆盖当前列表。
- 后台原生 select 声明深色 color-scheme，选项显式使用黑灰背景与浅色文字。详情摘要、角色选择与保存区统一使用现有后台按钮及黑灰卡片，保持自操作、角色权限和手机只读限制。

`npm run check` 通过：前端 719、后端 268、工具 18，共 1005 项，零失败或跳过；lint、maintenance 和正式 Vite 构建通过。独立复核通过跨工作空间删除标记、离线同步、换号和卸载期间排队删除的回归。

真实浏览器使用本地预览账户与 8 个合成项目：菜单最后一项位于最上层；7 个可删项全选、1 个只读项禁用；取消后仍为 8 项，确认后只保留只读项目且刷新一致。390px 下多选工具栏无横向溢出，角色编辑为只读；后台深色选项和服务筛选生效。测试项目已清理，无线上账户/项目变更或付费模型请求。

本轮未量化生产网络加载耗时。性能证据为执行真实 store 的受控测试：阻塞草稿读取仍可显示列表，同 scope 请求合并，失败后可重新请求，过时响应及删除竞态被隔离。浏览器、构建及上线附件位于 `output/workspace-feedback-2026-10-19/`，不纳入 Git。
