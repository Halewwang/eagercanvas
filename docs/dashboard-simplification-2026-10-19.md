# Dashboard 用户与服务管理精简

> 后续生产迁移、配置与发布已完成，整合版本见[main 发布说明](main-release-2026-10-19.md)。完整验收附件保存在本地 output/dashboard-release-2026-10-19，未纳入 Git。下文保留初次本地实施阶段的范围、验证与当时限制，不代表当前线上状态。

目标：管理后台仅处理注册用户的服务权限、角色和账户生命周期。

- 复用用户列表和详情作为 Dashboard；保留搜索、筛选、分页、角色修改、账户暂停/恢复/删除，以及服务开通/暂停/恢复。
- 移除 302 管理、余额、官方用量对账、凭据绑定和问题收件箱的页面、API、采集及后台任务。
- 复用 `user_service_credentials` 的状态记录作为服务授权，不为用户创建或绑定 key。文字、图片和视频均在账户与服务状态校验后使用服务器环境中的共享凭据。
- 保留后台权限校验、账户生命周期保护与操作审计。历史 SQL migration 和已有数据库数据不删除。
- 更新环境模板与验证入口；运行 lint、维护检查、前后端和脚本测试、构建，并用本地模拟数据检查桌面和窄屏页面。

本次仅修改本地代码和构建，不执行线上部署或真实模型请求。

部署时保留现有的账户操作发布开关：`ADMIN_LIFECYCLE_MUTATIONS_ENABLED=true` 才会接受管理写操作；关闭时返回维护错误。共享模型凭据仍只配置在服务器环境中，不返回给管理页面。新环境应按顺序应用现有 SQL migration，以提供服务授权表和账户操作锁。

验收范围：已用本地模拟用户检查桌面与 390px 窄屏、邮箱/服务筛选、用户详情及角色入口；操作菜单支持 Enter 打开、Escape 关闭和焦点回归，最后一行菜单不再被表格裁切。HTTP 自检确认已移除的 8 个接口返回 404、用户管理拒绝未登录访问。

限制：未部署、未修改线上数据库、未执行真实账户变更或模型付费请求。历史供应商 key 不会在上游自动撤销；历史 SQL 和数据保留。`git diff --check` 在 macOS 读取 Git 对象的 mmap 阶段持续阻塞，未把它记为通过。

最终本地验证：`npm run check` 通过（前端 662、后端 267、脚本 18，共 947 项测试；lint 和维护检查通过）；`npm run build` 通过。构建产物仅含用户列表和详情等保留模块，未检出已移除的管理接口与问题收件箱文案。另已修复服务筛选的历史授权边界：优先当前 active，否则取最新记录；create_failed 与无记录均按未开通处理。
