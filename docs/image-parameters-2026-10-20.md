- 新建空图片节点默认 `1:1 / 1K`，可预选比例与 `1K / 2K / 4K`；胶囊直接显示例如 `1:1`、`4K`，移除 `Export ratio`、`Export PNG` 文案式触发器。
- 参数独立保存在节点 `exportRatio / exportSize`，不作为模型生成参数。刷新、快照和复制保留选择；带媒体的新节点及已有图片缺省时保持 Original（原比例、原始像素），明确指定的空字符串和 0 不会被默认值覆盖。
