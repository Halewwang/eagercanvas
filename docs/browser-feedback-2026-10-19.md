# 浏览器反馈修复 · 2026-10-19

延续 [main 上线记录](main-release-2026-10-19.md)，处理图片节点、工作区侧栏与注册用户管理的六项反馈。

- 图片胶囊恢复 `Export ratio` 与 `Export PNG`。比例选择进入本地裁切预览，可拖动、缩放并取消；下载支持原始像素及 1024、2048、4096 像素长边。操作不会替换原图、改写节点或新增生成任务。
- 这些控件仅处理已有图片。Enbrand 生成尺寸的限制仍以 [实测记录](image-parameter-capabilities-2026-10-19.md) 为准；导出尺寸不作为模型参数。放大为本地插值，不增加 AI 细节。
- 删除 Background 菜单；保留已有画布数据的兼容读取。Tools 使用现有 Naive UI 菜单：空节点可上传图片，其余依赖图片的选项禁用；已有图片可替换、裁切并打开现有工具。
- 移除图片显示区域的内边距，按图片自然比例铺满内部容器，完整保留画面；裁切坐标与显示区域一致。
- 工作区侧栏删除调用次数、费用显示及其数据请求，清理专用格式化逻辑、props 和样式。
- 注册用户改为响应式卡片，服务、角色、账户操作直接显示。保留权限检查、自操作限制、确认弹窗及手机端只读行为；删除无人调用的旧列表组件。

验收使用本地预览账户与合成图片，未改写线上账户或项目，未调用付费模型。浏览器证据与上线核对保存在 `output/browser-feedback-2026-10-19/`。

`npm run check` 通过：前端 694、后端 268、工具 18，共 980 项，零失败或跳过；lint、maintenance 与正式 Vite 构建通过。独立复核覆盖原图坐标、缩放拖拽、细长图边界和多节点键盘裁切隔离。

真实浏览器核对了用户卡片筛选、账户确认弹窗、390px 手机只读、Tools 键盘打开和空节点禁用项。1600×800 合成原图导出得到 1024×512、800×800 和 1152×2048 PNG；多节点切换后仅保留当前裁切会话，80% 画布缩放下拖拽位移一致，Enter 下载后节点数据与历史未变。图片显示无内边距并完整铺满容器。
